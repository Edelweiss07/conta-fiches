# Conta Fiches

Web app per tenere il conto delle fiches di un numero variabile di giocatori (2–10), con un piatto al centro del tavolo per la mano in corso.

## Funzioni
- Configurazione iniziale: numero di giocatori, nomi e fiches iniziali
- Puntate con fiches da 1, 5, 10, 25, 100, 500, importo libero, **Vedi**, **All-in**, **Passa**
- Piatto centrale con totale, pile di fiches e contributo di ogni giocatore
- Assegnazione del piatto a uno o più vincitori (divisione automatica o manuale per piatti laterali)
- Nuova mano con piatto riportato o puntate restituite, rotazione del mazziere
- Annulla (Ctrl/⌘+Z), gestione giocatori (aggiungi, rimuovi, ricarica), registro delle azioni
- Stato salvato nel browser (localStorage)

## Uso
È un unico file `index.html` senza dipendenze: aprilo nel browser oppure pubblicalo con GitHub Pages.
